# Vehicle Dashboard

Aplicação web desenvolvida com Streamlit para análise exploratória de anúncios de carros.

## Funcionalidades

- Histograma de quilometragem
- Gráfico de dispersão entre preço e quilometragem
- Dashboard interativo

## Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit

- link do Render: https://projeto-5-88r1.onrender.com/
